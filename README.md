Работа над проектом отложена. Проект оказался достаточно большой, поэтому было принято решение доработать его, когда в моем арсенале будет еще и TypeScript (на данный момент знания теоретические, на уровне несложных задач). 

Пет-проект. Магазин одежды с учетом индивидуальных особенностей покупательниц. 

Преполагаемый стек: React, Redux Toolkit, TypeScript, SASS, БЭМ, JSON Server. Изначально вместо JSON Server предполагался mockApi.io, чтобы была возможность залить проект на Netify, но из-за ограничений сервиса, которые никак не снять, выбор пал на JSON Server. 

Проект по принципу: сначала работа над UI, потом добавление функционала.

ВЫПОЛНЕННЫЕ ЗАДАЧИ:
- организована файловая структура проекта
- созданы необходимые компоненты
- сделана стилизация (через SASS) на desktop
- реализован минимальный роутинг

ЗАДАЧИ, КОТОРЫЕ НУЖНО ВЫПОЛНИТЬ:
- стилизация на tablet и mobile
- вся логика приложения (подгрузка товаров, категорий, коллекций, подгрузка отдельного товара, управление корзиной, избранным, формирование заказа (добавление пользователем, просмотр и удаление администратором), добавление и редактирование товаров администратором, аутенфикация пользователя/администратора, работа с отзывами к товарам(подгрузка, добавление, удаление, редактирование)).
